# Customer Purchase Behavior & Revenue Analysis

This project presents a complete end-to-end data analytics workflow, designed to reflect real-world responsibilities of a Data Analyst. It demonstrates how raw data can be transformed into meaningful business insights using SQL, Python, Excel, and Power BI.

---

## Project Overview

The objective of this project is to analyze customer purchase behavior and generate actionable insights that support business decision-making.

This project covers the full analytics lifecycle:
- Data cleaning and preprocessing  
- Exploratory data analysis  
- SQL-based business problem solving  
- Dashboard creation and visualization  
- Insight generation and reporting  

---

## Key Objectives

- Analyze customer purchasing patterns  
- Identify high-value customers and revenue contributors  
- Track sales performance and trends  
- Understand factors influencing customer behavior  
- Provide data-driven business recommendations  

---

## Tools & Technologies

- SQL – Data querying and business analysis  
- Python (Pandas, NumPy) – Data cleaning and preprocessing  
- Microsoft Excel – Initial data exploration  
- Power BI – Dashboard creation and visualization  

---

## Project Workflow

### 1. Data Preparation (Python & Excel)
- Imported raw dataset  
- Handled missing values and inconsistencies  
- Performed data transformation  

### 2. Exploratory Data Analysis
- Identified trends and patterns in customer data  
- Analyzed sales distribution and behavior  

### 3. SQL Analysis
- Wrote queries to answer key business questions  
- Used joins, aggregations, and filtering  
- Performed customer segmentation and revenue analysis  

### 4. Dashboard Development (Power BI)
- Built an interactive dashboard  
- Visualized KPIs such as revenue, customer segments, and trends  
- Added filters for dynamic analysis  

### 5. Insights & Recommendations
- Identified top-performing customer segments  
- Highlighted revenue-driving factors  
- Suggested strategies for improving sales and retention  

---

## Key Insights

- Top customers contribute a significant portion of total revenue  
- Certain product categories drive higher repeat purchases  
- Seasonal trends impact overall sales performance  
- Customer segmentation helps target high-value users effectively
